# risc5_32i-processor_uvm.
A 32-bit Single-Cycle RISC-V (RV32I) processor designed and implemented from scratch in SystemVerilog. Supports core integer instructions (ADDI, ADD, SUB, AND, OR, LW, SW, and BEQ) with a complete datapath and control unit. Verified through RTL simulation and waveform analysis using Icarus Verilog on EDA Playground.
